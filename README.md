## ⚙ Rules this repo runs on

1. **State the metric before building.** "It works" is not an outcome.
2. **Every number carries a unit**, and the instrument that produced it is named.
3. **Raw data is committed**, not just the plot. A plot without data behind it is a claim.
4. **Quote versus measured.** Where a datasheet or a forum said one thing and the meter said another, both numbers go in the README. That gap is the entire reason for doing the work.
5. **One folder per mission.** No folder is renamed after it is pushed.

---

## 🧭 Reading order for a stranger

Start with the most recent row in the index that has a number in it. Every folder is self-contained.
